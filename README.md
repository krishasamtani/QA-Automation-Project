# QA Playwright Automation Framework (Python)

An end-to-end UI automation testing framework built using **Python**, **Playwright**, and **Pytest** targeting the SauceDemo e-commerce application.

## Features Tested
- **User Authentication:** Valid login, invalid login, locked-out user scenarios.
- **Cart Management:** Adding items to cart, verifying cart badge, removing items.
- **Checkout Flow:** Handling missing mandatory fields, completing successful checkout.
- **Session Management:** Secure user logout functionality.

## Tech Stack
- **Language:** Python
- **Automation Tool:** Playwright (Sync API)
- **Test Runner:** Pytest
